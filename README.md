# ExploreAsia360 Landing Page

Static travel landing page for ExploreAsia360 with:

- luxury-style hero section
- interactive quick planner
- detailed trip inquiry form
- responsive layout and sticky WhatsApp CTA

## Local Files

- `index.html`
- `styles.css`
- `script.js`

## Deployment

This project is designed to be published as a static site, including GitHub Pages.
